# runs/wirachat

| Folder | What it is |
|---|---|
| [`final/`](final/README.md) | **Final code** that produced the submitted files (one notebook per task, how to run, requirements). Start here. |
| [`report/`](report/) | Technical report. |
| `round-1/`, `round-2/`, `round-3/` | **Experiments** (trial and error, diagnostics, alternative models, every Kaggle score in `notes.md`). Kept for the record, not needed to reproduce the submission. |

The experiment folders are separate from `final/`: nothing in `final/` imports from them.
